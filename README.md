# COMP 3005 — Introducción al Uso de la Computadora (UPR-Humacao)

Sitio del curso y cuadernos de Colab para COMP 3005: un curso introductorio de
**programación en Python** orientado a aplicaciones en **biología y química**.
Sin prerequisitos.

Este repositorio se genera desde un repositorio privado maestro — por favor no lo
edites directamente; los cambios llegan aquí mediante el flujo de publicación del
curso.

**Sitio del curso:** https://devomh.github.io/comp3005-2026/

Cada nota de concepto enlaza su laboratorio práctico, y el distintivo
*Open in Colab* de cada página abre el cuaderno correspondiente directamente desde
este repositorio.

## Contenido

| Módulo | Carpeta |
|--------|---------|
| Módulo 1 — Fundamentos y programación básica | `u01_fundamentals` |
| Módulo 2 — Estructuras de datos, funciones y archivos | `u02_data_structures_files` |
| Módulo 3 — Cómputo científico con Python | `u03_scientific_computing` |

Las salidas de los cuadernos son reales: se producen ejecutando el código en un
entorno con versiones fijadas, no se escriben a mano.
